# 战斗地图八格地形图集设计

## 目标

为战棋战斗地图制作第一版完整基础地形图集，替换当前以纯色矩形和文字标签为主的地形视觉。素材需要与既有 Q 版像素武将统一，同时让相邻地图格看起来像连续战场，而不是八个有硬边的独立色块。

## 资源规格

- 图集尺寸：`544×68` 像素。
- 单格尺寸：`68×68` 像素，与 `BattleScene` 当前 `CELL_SIZE` 一致。
- 横向 8 格，固定顺序：
  1. 草地 `grass`
  2. 平原 `plain`
  3. 山地 `hill`
  4. 森林 `forest`
  5. 村庄 `village`
  6. 城池 `city`
  7. 营寨 `camp`
  8. 河流 `river`
- 交付 PNG 图集、生产副本和 JSON 素材清单。

## 视觉设计

- 使用无描边 Q 版像素风，依靠色相、纹理和明暗区分地形。
- 草地与平原使用低对比连续底纹，避免降低单位可读性。
- 山地与森林的主体保持在本格内部，不跨格穿插；主体用像素色块和局部阴影表现，不使用黑色外轮廓。
- 村庄、城池、营寨采用居中的建筑主体，并保留足够底色边缘，避免遮挡单位脚下位置。
- 河流使用蓝青水面、少量横向波纹和柔和岸线，不加入桥梁或文字。
- 不在图集中绘制格子边框、阵营色、单位、移动范围、攻击范围或选中状态；这些状态由 Phaser 代码层负责叠加。

## 接入边界

- `BattleScene` 继续使用现有地形编号和战斗规则，只替换地形底图渲染。
- 地图交互区域仍由代码创建，素材不得覆盖可点击层的语义。
- 旧的颜色回退保留为资源加载失败时的安全回退。
- 地形名称不再绘制在格子内，避免缩放和字体编码问题；选中单位的状态栏继续显示地形名称。

## 验收标准

- 八格顺序与 `BAYE_TERRAINS` 完全一致，尺寸均为 `68×68`。
- 相邻同类地形拼接时没有明显黑边或硬描边断层。
- 兵种小人放入格子后仍有清晰的轮廓、足部空间和敌我状态反馈。
- 建筑类地形不会跨格、穿透单位或遮挡交互热区。
- 资源清单、代码引用和生产文件路径一致；失败时仍能使用颜色回退。
