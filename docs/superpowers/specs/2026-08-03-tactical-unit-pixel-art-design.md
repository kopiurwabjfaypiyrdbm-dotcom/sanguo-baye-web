# 战棋六兵种像素形象设计

## 目标

将战棋棋盘中的文字武将标记替换为可辨识的兵种小人像。地图格子只显示兵种形象与必要的选中/敌我反馈；武将姓名、兵力、等级、行动状态等信息统一在选中后的独立状态栏显示。

本阶段只改变战棋视觉表现与信息层级，不改变战斗规则、兵种克制、移动、攻击、技能或结算逻辑。

## 视觉方向

- 参考步步高电子词典版《三国霸业》的低分辨率像素识别方式，但不复制未获授权的原版素材。
- 以东汉末年至三国时期的服饰、甲胄和兵器为考据基础，采用简化后的像素轮廓表达。
- 六个兵种使用统一的基准尺寸、落脚线、视角和光照；通过武器、姿态和轮廓区分兵种，而不是依靠文字。
- 素材为透明背景 PNG，不包含中文、数字、徽标或现代 UI 符号。
- 颜色使用低饱和朱砂、黛蓝、青灰、旧金和皮革棕；敌我阵营由代码层的边框/光晕表达，不把阵营颜色烘焙进人物主体。

## 六兵种定义

| 兵种 | 形象与装备 | 识别重点 |
| --- | --- | --- |
| 步兵 | 札甲或皮甲、圆盾、环首长剑 | 盾牌在身体前侧，长剑向下或斜持，站姿稳定 |
| 骑兵 | 骑乘战马、札甲、长矛 | 马匹轮廓与前伸长矛形成横向识别线 |
| 弓兵 | 轻札甲或皮甲、复合弓、箭囊 | 拉弓或持弓待发姿势，弓弦和箭囊清晰 |
| 水兵 | 轻札甲或短襦、幅巾或简式头盔、环首刀与轻便短兵器 | 轻装、便于船上行动；不使用海盗式服饰或幻想海军元素 |
| 极兵 | 重札甲、重骑战马、长柄重兵器 | 体量和甲片明显厚重，轮廓区别于普通骑兵 |
| 玄兵 | 羽扇纶巾、宽袖长袍、文士冠服、羽扇 | 以谋士身份和文士装备识别，不设计成法师、巫师或超自然角色 |

“水兵”的具体短兵器和头部装束允许在第一版素材中做小范围视觉取舍，但必须保持汉末水军轻装、船战适应性和历史服饰边界。“玄兵”是兵种在战棋中的视觉身份，不代表增加法术规则。

## 棋盘接入

`src/game/BattleScene.ts` 负责加载并渲染六个兵种素材：

- 删除棋盘单位上的武将姓名和兵力文字。
- 以 `armsType` 映射到六个独立的兵种 PNG。
- 小人像居中落在格子内，保留现有单位点击事件。
- 已行动单位使用透明度降低；被选中单位使用金色描边/底部高亮；可攻击单位保留红色提示；敌我阵营保留现有的颜色反馈。
- 图片加载失败时使用简洁的代码绘制回退标记，保证战斗仍可操作，但不回退到棋盘文字信息。

`src/ui/TacticalBattleScreen.tsx` 负责信息层：

- 现有底部 `battle-selection-card` 调整为选中状态栏，显示武将姓名、兵种、兵力、等级/行动状态等核心信息。
- 详细信息面板继续提供移动、攻击、地形、技能点、装备和状态等扩展字段。
- 未选中单位时，状态栏显示引导语；棋盘不显示任何武将姓名或兵力数字。

## 资源规范

- 资源目录：`assets/production/tactical/units/`。
- 源图目录：`assets/source/tactical/units/`，保留生成源图和必要的裁切记录。
- 每个兵种一个稳定文件名：`infantry-v1.png`、`cavalry-v1.png`、`archer-v1.png`、`navy-v1.png`、`elite-cavalry-v1.png`、`mystic-strategist-v1.png`。
- 基准画布约为 `64×72` 像素；主体留出至少 2 像素安全边距，脚底保持同一水平线。
- 在资源清单中记录生成提示、风格说明、版本和人工验收结果；不把原版二进制资源或未核验来源文件加入产品。

## 验收标准

1. 六种 `armsType` 均能在战棋格子中显示正确小人像。
2. 棋盘单位不再渲染武将姓名或兵力文字；选中后状态栏显示这些信息。
3. 选中、可攻击、已行动、敌我阵营等现有交互反馈仍可辨识。
4. 素材在桌面横屏和移动横屏尺寸下都不遮挡格子边界，六种轮廓可快速区分。
5. 图片加载失败时战斗仍可继续操作。
6. 不修改战斗规则和状态数据结构；现有战斗测试与构建检查继续通过。

## 范围外

- 本阶段不制作走路、攻击、受击等动画帧。
- 本阶段不为每名武将制作独立头像或人物立绘。
- 本阶段不调整兵种属性、兵种克制、兵器加成或战斗公式。
