# 选择君主与战略按钮美术设计

## 目标

为选择君主界面的君主名称、战略界面的功能按钮补充可复用的古风写实视觉素材，同时保持现有交互、键盘可操作性、响应式布局和按钮文本可访问性。

## 视觉方向

整体采用“漆木棕黑 + 暗金选中 + 旧宣纸文字 + 朱砂点缀”。相比现有偏现代的墨绿色，漆木、铜饰和纸张的组合更接近古代器物与战略案牍。

- 默认底色：乌木黑、深褐漆色。
- 面板层次：旧木棕与半透明深褐。
- 边框与图标：暗金铜色，局部使用磨损和低对比高光。
- 文字：旧宣纸色，辅助信息降低亮度。
- 选中态：暖金描边、淡琥珀内光或金线底纹；不使用朱砂作为选中主色。
- 朱砂：只用于印章、危险操作和少量重要提示。

## 设计范围

### 选择君主界面

将君主列表按钮表现为势力铭牌：深褐漆底、暗金边框、轻微纸纹/木纹质感。君主名称继续使用 HTML 文本，城池和武将数量作为次级信息保留在铭牌内部。

- 默认：低对比暗金边框。
- 悬停与键盘聚焦：边框提亮并出现短促内光。
- 选中：暖金外框、淡琥珀底纹和小型金色印记；保持与未选中项的尺寸一致。
- 禁用：降低亮度和对比度，不改变布局。

### 战略界面

统一顶部地图操作与底部战略导航的按钮语言。重点功能包括情报、城池、人物、宝物、委任、结束本月，以及本势力、全天下、菜单。

- 功能按钮使用无文字图标素材，中文标签仍由 HTML 渲染。
- 当前导航项使用暗金高亮，不使用朱砂填充。
- 结束本月保留更强的金色层级；不可用状态保持轮廓可辨识。
- 图标在桌面与移动端按同一视觉比例缩放，触控热区不小于现有规范。

## 素材与代码边界

沿用工作区已经建立的可追溯按钮素材目录：

- `assets/source/ui/`：带色键的源素材。
- `assets/production/ui/`：应用运行时引用的优化 PNG 素材。
- `assets/manifests/ui-button-art.json`：素材用途、尺寸、生成方式和来源记录。

本轮在现有 `ruler-card-frame-v1` 与 `strategic-nav-frame-v1` 基础上校准色彩和状态表现，不另起一套目录或覆盖工作区已有素材。

素材只负责边框、底纹、印记和图标，不嵌入中文按钮文案，避免文字变体、缩放模糊和辅助技术不可读。React 组件继续负责按钮语义、状态和事件，CSS 负责尺寸、布局、响应式和状态叠加。

## 验收标准

- 选择君主界面能够清楚区分默认、悬停、键盘聚焦、选中和禁用状态。
- 战略界面的顶部与底部功能按钮看起来属于同一套古风写实组件系统。
- 选中态以暖金/琥珀为主，朱砂仅作为点缀，不会让普通选择看起来像危险操作。
- 中文文案仍为 DOM 文本，按钮仍支持键盘和触摸操作。
- 桌面宽屏、窄屏和 Android 规则下无文字溢出、按钮裁切或触控热区退化。
- 遵守项目素材安全规则，不引入原版受限资源；补充 provenance 记录。
- `npm run check` 通过。
