# MB05 城池经济与开发规则完成报告

日期：2026-08-03
引擎：Godot 4.7.1 stable official `a13da4feb`
语言：GDScript

## 结果

生产 `GameSession` 已支持完整七项内政事务：开垦、招商、治理、出巡、交易、宴请和掠夺。六项新增规则位于纯 `RefCounted` 领域模块，应用层以显式 adapter 注册；场景仍只提交 command envelope 并渲染 query DTO。

规则移植保持 Web 的命令成本、有效装备属性、资源上限、行动标记、日志和 RNG 调用次数。交易、宴请与掠夺不推进 seed；四项开发/治理类随机命令在所有结构和领域前置条件通过后才调用显式 LCG。失败不会改变 seed、资源、体力、行动列表或日志。

## 确定性证据

共享 application-session fixture 当前包含 37 路事务：MB04 13 路基线、12 路连续内政序列、11 路独立规则边界，以及 1 路跨语言无效状态。连续序列覆盖卖粮、开垦、招商、治理、出巡、宴请、掠夺、资源不足买粮、成功买粮、非法数量、Unicode 标量未知字段顺序及已行动人物拒绝；独立边界覆盖农商上限、异常城池治理、出巡双上限、装备智力增益、君主宴请上限、掠夺资源上限及现代 inspect/trade/banquet/plunder 成本。每步 result core、receipt、返回 state 载荷 SHA 与会话 after state SHA 均由 TypeScript oracle 生成并由 Godot 4.7.1 对照。

另有 `modern-balanced-v1` 治理案例验证现代规则集的 4 体力/50 金成本，防止实现只编码经典规则集的 8 体力/50 金。
