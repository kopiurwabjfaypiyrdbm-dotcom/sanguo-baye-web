# MB07 人才登用与俘虏处置完成报告

日期：2026-08-03  
引擎：Godot 4.7.1 stable official `a13da4feb`  
语言：GDScript

## 结果

生产 `GameSession` 已支持搜寻人才、登用本城已发现的在野人物、招降/释放/处斩本城俘虏、流放在职人物或俘虏，以及没收单件装备。七项命令由纯 `RefCounted` 领域模块实现，经显式 application adapter 和统一事务边界提交；新增的原生“人才与俘虏”面板只消费 query DTO、发送 command intent，不直接计算资格、随机分支、忠诚、流放目的地或装备回收。

实现保持 Web 产品的显式 seed 与条件式 RNG 调用、搜寻/登用 8 点体力成本、classic 招降 15 体力/100 金与 modern 招降 4 体力/0 金、行动占用、已发现集合、俘虏原势力/羁押势力元数据、处斩死亡记录与装备回收、38 城稳定流放目标、太守修复、玩家君主保护和没收特例。失败不会推进 seed 或产生部分状态。

## 原生交互

城池空间卡片新增独立“人才”入口，与“人物”和七项内政命令分离。原生面板支持前后切换七项命令，并按 DTO 选择目标、执行者和装备；处斩、流放与没收使用中文原生危险确认。执行或取消后保持城池上下文并刷新状态、seed 与不可用原因。

844×390 的紧凑布局保持主要控件和确认按钮至少 48px 级物理目标，面板未侵入底部状态区；1280×720 显示完整摘要与空间地图背景。呈现烟测在真实主场景上构造合法在野、俘虏和装备状态，覆盖七项固定顺序、依赖选择、危险确认、释放事务及窄屏布局。
