# 开发日志

## 2026-08-02：移动端单层城池命令编辑器

### 已完成

- 保留“城市节点 → 分类 → 具体命令”的地图锚定层级；具体命令改为单一聚焦编辑器，普通命令在同层展示执行者、参数、预期效果、成本、行动消耗和禁用原因后直接提交，不再打开通用复核弹窗。
- 仅掠夺、流放、非君主装备没收、俘虏流放与处斩等不可逆操作保留一次简短危险确认；取消会回到原命令编辑器且保留当前选择。
- 命令目录统一记录快速/复杂编辑器密度和固定危险属性；长表单可在内容区触控滚动，命令标题、返回入口和底部主操作保持可见，全局战役底栏在编辑器期间让位。
- 分类菜单会提前禁用并说明无人才、无俘虏、无道具、无道路目标、无敌邻、无侦察/谋略目标和经典规则自动太守等已知结构性不可用状态，避免进入无解释的死路。
- 21 个现有城池命令仍由原有核心回调执行；本轮没有修改规则、成本、随机数、存档或日志路径。
- Vitest 固定为单工作线程运行；检查时间略增，但避免并行测试池与开发服务器或 Android 构建争抢 CPU，并消除本机测试工作进程异常退出。

### 验证状态

- `npm run check` 通过：51 个固定 C 参考文件校验、358 项测试通过、4 项本地参考测试跳过，TypeScript、Vite 生产构建与 PWA 产物生成成功。
- 844×390 浏览器实测开垦普通命令直接完成且没有第四层复核；效果、成本、禁用原因和固定主按钮无互相遮挡，执行后回到原内政分类。
- 掠夺实测会因已行动武将显示即时禁用原因，切换可行动武将后只出现一次危险警告，取消可回到保留选择的命令编辑器。
- 输送在 667×375、844×390 和 1462×822 下均无页面滚动或全局底栏重叠；内部滑动后货物字段可达且底部主操作保持不动。
- Escape 返回链实测为“危险确认 → 命令编辑器 → 分类 → 城市根菜单 → 地图”，回到地图后全局底栏恢复。
- Debug APK 已完成构建、安装并在 MuMu 横屏模拟器实测；命令编辑器显示、内部触控滑动、固定主操作及 Android 系统返回链均通过。
- 验收结束后关闭 5180 开发服务；空闲采样中所有 Node 进程 2 秒 CPU 增量均为 0，未发现由命令编辑器引入的持续循环。
