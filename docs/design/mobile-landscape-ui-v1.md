# 手机横屏 UI 交互方案 v1

## 目标

将手机横屏全屏确立为第一交互平台，同时让桌面端复用同一套组件和状态模型。方案不改变核心规则，只重组信息层级、命令路径和触控反馈。

核心体验可以概括为：

> 地图常驻、点物下令、层层聚焦、统一推进、战术独立。

玩家在战略阶段反复完成“看地图 → 点城市 → 选动作 → 确认命令 → 回到地图”，在月末统一观察 AI、在途命令、战斗和事件的结算结果。

## 参考取舍

### 《三国志·战略版》

吸收地图优先、对象触发情境命令、顶部资源摘要、底部全局入口和触控优先的设计。不复制 MMO 地块铺路、社交、赛季、计时建造和商业化入口。

### 电子词典原版《三国霸业》

保留“城市 → 命令类别 → 具体命令 → 武将/目标/数量 → 确认”的可返回命令链，以及玩家下令后统一执行队列的节奏。不复制 160×96 屏幕、键盘光标和超长文字菜单。

### 《三国志9》

吸收一张地图承载态势、集中计划后统一推进、在途部队与行动可视化。不复制 PC 密集窗口、右键语义和自动战斗优先。

## 信息架构

### 常驻层：战略地图

- 地图占手机横屏可用面积的 75%–90%。
- 顶栏只显示年月、核心资源、在途命令数量、全屏/设置和“结束本月”。
- 底栏只放全局入口：地图、势力、人物、战报、系统。
- 城市、路线、在途命令和风险提示直接编码在地图上。

### 情境层：据点四叶草（CoC 式）

- 点击城市后，在据点周围展开放射花瓣（详情 / 内政 / 人事 / 军事 / 谋略），不把 L2 做成右侧整页工作台。
- 点花瓣后收起放射菜单，再打开该类 L3 短面板（底部命令条或近侧短板）。
- 敌城显示情报类花瓣；空城显示占领条件；己方城市显示经营类别。
- 详细规范见 [`coc-style-city-radial-ui.md`](./coc-style-city-radial-ui.md)。
- 点击地图空白、返回键关闭当前层；从 L3 返回应回到四叶草。

### 任务层：分步命令

统一命令路径：

1. 选择命令。
2. 选择执行武将。
3. 选择目标或数量。
4. 查看成本、风险、路径和结果预估。
5. 确认下令并返回地图。

每个命令面板只显示当前步骤需要的信息。目标城市和路线仍在地图上高亮，避免失去空间上下文。

### 推进层：月末检查

结束本月前显示：

- 已下达的战略和谋略命令。
- 尚未行动的武将。
- 粮草、空城、边境兵力等风险。
- 预计会在本月到达或触发的事件。

确认后进入不可编辑的短暂推进态：地图依次表现 AI 下令、运输、调动、谋略、战斗和月度事件，然后呈现可折叠月报。

### 战术层：独立战场

- 战场占据绝大部分画面。
- 流程保持原版节奏：选武将 → 移动 → 普攻/计谋/待机 → 目标 → 确认。
- 队伍列表、单位详情、技能说明和日志使用边缘抽屉，不长期压缩战场。
- 当前武将的主要动作固定在底部拇指可达区。

## 横屏布局基线

- 设计母版：1600×900，等比缩放到常见 16:9 与更宽设备。
- 最小验收：667×375 CSS 像素。
- 主要点击目标不小于 44×44 CSS 像素。
- 顶栏目标高度 44–52 CSS 像素；底栏目标高度 52–64 CSS 像素。
- 使用动态视口高度和安全区内边距，不以固定 `100vh` 假定浏览器栏高度。
- 使用 `(orientation: landscape)`、`max-height`、`pointer: coarse` 和容器宽度共同判断布局，不以单一宽度断点或 UA 判断。

## 交互约束

- 单击负责选择，明确按钮负责执行；不把双击作为唯一入口。
- 拖动地图与点选城市需要移动阈值，避免误触。
- 地图支持单指拖动与双指缩放；城市可视标记之外增加透明触控热区。
- 关键说明不依赖 `hover` 或 HTML `title`。
- 数值输入优先使用减号、滑杆、加号、最大值和预设比例，软键盘只作为补充。
- 危险操作在原操作位置附近二次确认，避免弹出离手指很远的确认框。
- 任意命令步骤都能返回上一级，已选武将、目标和数值在合法时保留。

## 视觉主旋律

- 深青绿色沙盘作为长期背景，米色纸面承载需要阅读的详情。
- 金色只强调选中、关键资源和主操作；红色只用于风险、敌对和破坏性操作。
- 势力颜色必须同时配合旗形、名称或纹理，不能只靠颜色区分。
- 地图标记和路径优先于装饰；头像和插画只在人物选择、事件和战斗结果中承担叙事作用。
- 动画以 120–240ms 的抽屉、路径和选择反馈为主；月末推进和战斗结果可使用更完整的短演出。

## 推荐实施顺序

1. 新建移动游戏壳：动态视口、安全区、紧凑顶栏、底栏和通用抽屉。
2. 将现有 `CityPanel` 拆成城市摘要、类别入口和分步命令组件。
3. 改造 Phaser 战略地图的触控热区、手势和命令路径覆盖层。
4. 加入月末检查和统一推进表现。
5. 重构战术战场为地图优先、底部动作栏和边缘队伍抽屉。
6. 补齐全屏、主屏安装、横屏提示、真机回归和桌面适配。

## 验收场景

- 从标题页开始新战役并选择时期、规则和君主。
- 在不纵向滚动整个页面的情况下完成开垦、搜索、奖赏、调动、侦察和出征。
- 从地图明确看到所选城市、目标城市、预计成本、路径和在途状态。
- 结束月份前可以识别未行动武将和高风险城市。
- 完成一次手动战斗的选择武将、移动、普通攻击、计谋、待机和撤退。
- 保存、载入、旋转屏幕、退出全屏和重新进入后界面状态合法。
- 667×375、844×390、915×412、平板横屏和桌面浏览器均不存在关键按钮遮挡或双层页面滚动。
