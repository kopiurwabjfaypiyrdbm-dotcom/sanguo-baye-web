# 开局流程

现代开局流程沿用原版 `gamEng.c:GamMainChose` 的信息顺序：主菜单选择“新君登基”，进入四时期菜单，随后选择玩家君主。视觉上不复制原版位图，而是保留深色 LCD 氛围、二乘二时期布局和原版菜单命名，并使用适合现代宽屏的信息卡片呈现。

```text
标题屏
  ├─ 新君登基 → 四时期选择 → 君主选择 → 38 城战略地图
  └─ 重返沙场 → 自动存档 → 战略地图
```

四时期的城市、道路、人物和势力记录由本地权威 `dat.lib.orig` 解析后生成到 `src/data/generated/baye-periods.json`。生成器校验锁定的 SHA-256，发布包不包含原始资源容器、图片或字体。任何时期都必须先通过领域状态校验，才允许作为内置剧本进入游戏。
