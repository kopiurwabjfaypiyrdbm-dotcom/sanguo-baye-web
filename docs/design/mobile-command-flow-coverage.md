# 移动端统一命令流覆盖清单

本清单记录 `mobile-unified-command-flow` 阶段迁移后的玩家命令入口。所有实际状态变更统一经过“命令意图 → 参数选择 → 结果预览 → 明确确认”，规则合法性、数值、随机性和日志仍由 `src/core/` 与 `src/compat/baye/` 负责。

## 统一交互约定

- 命令按钮只负责打开预览；取消不会改变游戏状态，确认才调用原有命令回调。
- 预览统一展示类别、城市、执行者、目标、预期影响、资源或行动成本以及必要风险。
- 不可执行时，按钮保持禁用并通过附近提示或 `title` 说明具体原因。
- 不可逆命令使用危险样式和更明确的确认文案。
- 对话框支持触摸、键盘焦点约束、`Escape` 取消和关闭后焦点恢复。

## 命令覆盖

| 类别 | 已覆盖命令 | 参数或选择 | 预览重点 |
| --- | --- | --- | --- |
| 内政 | 开垦、征兵、搜寻、招商、治理、出巡 | 执行武将；征兵数量使用既有规则默认值 | 增益范围、金钱、体力、本月行动 |
| 内政扩展 | 交易、宴请、掠夺 | 买卖方向与数量；宴请对象；掠夺执行者 | 资源变化、忠诚变化、城市风险；掠夺为危险操作 |
| 人事 | 登用、调动、任命太守、奖赏、流放 | 人物、执行者、相邻目标城 | 成功影响、旅程耗时、身份变化、忠诚与不可逆风险 |
| 道具装备 | 赏赐道具、卸下装备、没收装备 | 人物与道具 | 属性或忠诚影响、道具归属、没收风险 |
| 俘虏 | 招降、释放、流放、处斩 | 俘虏与招降执行者 | 成本、确定性判定因素、去向；流放和处斩为危险操作 |
| 谋略 | 离间、招揽、反间、诱敌 | 执行者、已侦察人物目标 | 月份耗时、金钱、体力、判定因素与延迟结算 |
| 军事 | 输送、侦察、分配兵力、筹划出征 | 相邻目标城、资源数量、执行者、最多十名出征武将、粮草 | 跨城耗时、资源去向、情报时效、兵力前后值与出征总量 |

## 仍由后续界面负责的二级决策

“筹划出征”确认后出现的亲自指挥或快速结算，是战斗模式选择而非另一条城池命令。本阶段保留其现有入口；战术操作会在 `mobile-tactical-battle-interface` 阶段统一为横屏触控界面。

## 验收样例

- 成功与确定性：开垦预览的范围来自核心计算，确认后沿用既有命令路径并写入日志。
- 取消与焦点：预览中取消或按 `Escape` 不改变状态，只关闭预览并把焦点还给来源按钮。
- 禁用与资源不足：已行动、体力不足、金钱不足或目标非法时禁止打开预览，并显示规则原因。
- 数量：交易、输送、分配兵力和出征粮草先编辑数量，再在预览中复核。
- 目标与跨城：调动、输送、侦察和出征明确展示来源城市与目标城市。
- 多武将：出征保留最多十人的复选和总兵力预览。
- 危险操作：掠夺、流放、没收装备和处斩使用危险提示，不允许点击一次直接执行。
