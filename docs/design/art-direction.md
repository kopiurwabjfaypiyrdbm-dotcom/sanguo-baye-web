# Web 三国霸业美术方向

## 目标

视觉设计服务于两个目标：让熟悉步步高电子词典版《三国霸业》的玩家立即认出其信息结构与操作节奏，同时让现代屏幕上的地图、文字、战斗范围和资源状态清晰易读。

不直接使用来源不明的原版美术。通过重新绘制来保留视觉语法，并用经典主题支持对照与怀旧体验。

## 双主题

### Classic

- 使用原版逻辑画布和整数倍 nearest-neighbor 缩放。
- 低色阶或单色调色板、像素边框、反显焦点和紧凑菜单。
- 保留方向键式焦点顺序，同时允许触摸和鼠标操作。
- 用于视觉回归、原版流程对照和怀旧模式。

### Modern

- 米纸背景、深墨文本、铜金强调和朱砂警示构成有限色板。
- 主地图采用简化水墨地形、印章式城池和高辨识度道路。
- 战场保持清晰网格，地形块使用统一俯视角和有限纹理密度。
- 武将头像统一半身构图、光源、视角、边框和服饰考据等级。
- 动效集中于焦点、行军、受击、占领和回合切换，避免干扰策略阅读。

两套主题只改变表现，不复制游戏状态或规则。

## 设计令牌

界面颜色、字体、间距、边框、阴影、动画时长和地图势力色必须从主题令牌读取。React 面板、Phaser 地图和未来战场不得各自硬编码一套视觉常量。

建议首批令牌：

```text
surface.canvas
surface.panel
surface.overlay
text.primary
text.muted
accent.action
accent.danger
border.subtle
focus.primary
faction.*
motion.fast
motion.normal
grid.cellSize
```

## 资产管线

```text
观察原版画面
  -> 记录信息结构和视觉语法
  -> 黑白线框验证布局
  -> 制作自有源文件
  -> 导出 Web 资产和 atlas
  -> 登记来源与许可证
  -> Classic/Modern 双主题视觉回归
```

正式资产放在 `assets/production/`，可编辑源文件放在 `assets/source/`，来源清单放在 `assets/manifests/`。在建立实际资产前不创建空目录占位。

## 首批美术里程碑

1. 采集主菜单、时期选择、战略地图、城池信息和战场五类原版界面。
2. 完成 Classic 主题的基础调色板、字体度量、焦点框和窗口组件。
3. 完成 Modern 主题的主地图、右侧城池信息和底部日志线框。
4. 绘制 6 类地形测试块、3 个势力城池标记和 4 个统一风格头像样例。
5. 在桌面 1080p、800p 横屏和移动竖屏进行可读性验收。

## 验收原则

- 不看文字也能分辨可操作、选中、不可用和敌对状态。
- 地图缩放后城池归属与连接关系仍清楚。
- Classic 模式的焦点顺序和信息密度可与原版截图逐项对照。
- Modern 模式不改变命令含义、回合节奏和战场格子语义。
- 所有正式资产均有可追溯来源。
