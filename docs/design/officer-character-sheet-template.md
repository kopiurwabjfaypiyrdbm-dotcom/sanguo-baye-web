# 武将人物设定总板模板

## 目标

为最终近 500 名武将提供统一、可批量替换的横向人物设定图模板。首个案例为张飞，用于验证力量型近战武将的表现方式。

## 画板结构

- 左侧约 30%：武将半身头像、姓名“张飞”、身份标签。
- 中间约 25%：战斗界面战棋形象，使用俯视/等距视角的小比例战斗单位。
- 右侧约 45%：五个动作参考位，依次为待机、攻击、受击、移动、施法。
- 画面不使用纸张背景、装饰边框或复杂分割线，优先保证角色与动作的可读性。

## 角色与美术方向

- 三国历史感与写实厚涂概念设计结合，延续项目的低饱和、冷暖克制美术气质。
- 张飞作为力量型近战武将：豹头环眼、黑须、魁梧体格、玄黑重甲/战袍、丈八蛇矛。
- 主色偏暗红、玄黑、旧金，避免鲜艳卡通化。
- 五个动作必须保持同一脸部、服装、武器、比例与材质，只改变姿态和受力方向。

## 交付标准

- 姓名与动作标签清晰可读。
- 头像、战棋形象、五个动作在同一画板内能快速对应。
- 版式可直接复制给其他武将，只替换角色设定与动作内容。
- 任何“原作一致”判断仍需以项目既有证据或可复现对比为准；本图属于统一视觉模板，不宣称原作素材复刻。
