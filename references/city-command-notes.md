# 城市经营命令对照笔记

本笔记记录招商、治理、出巡、交易、宴请与掠夺的固定 C 证据和 Web 产品差异。事实源均来自锁定的 MIT 参考子集 `references/vendor/baye-c-core/`。

## 招商

- `baye/order.h` 将 `ACCRACTBUSINESS` 定义为内政命令，并声明体力常量 4。
- `citycmdb.c:AccractbusinessMake` 检查商业上限和金钱，选择执行者后按 `IQ / 10 * (rand % 4 + 2) + (IQ >> 1)` 增加商业，并截断到城市商业上限。
- 当前 Web 版通过装备后的有效智力保留智力与 2–5 随机因子的增量形状及城市上限；为与既有开垦产品节奏对称，暂用 50 金、8 体力。固定运行时金钱/体力资源表未进入 allowlist，因此这两个成本不声明原版一致。

## 治理

- `citycmdb.c:FatherMake` 检查金钱；把城市状态恢复为正常，并以 `1 + rand % 4` 增加防灾，最高 100。
- `citycmd.c:FatherDrv` 只把执行者放回城市；主要效果已在命令创建阶段写入。
- 当前 Web 状态尚未接入灾害类型，所以本阶段只保留防灾 1–4 与 100 上限；“恢复正常状态”留给 v0.5 城市事件。成本暂为 50 金、4 体力。

## 出巡

- `citycmdb.c:InspectionMake` 以 `1 + rand % 4` 增加民忠（最高 100），并增加人口 100（不超过人口上限）。
- `citycmd.c:InspectionDrv` 只把执行者放回城市。
- 当前 Web 版保留上述增量和上限；成本暂为 50 金、4 体力。

## 交易、宴请与掠夺

- `citycmdc.c:ExchangeMake`：买入每 1 粮消耗 5 金；卖出每 1 粮获得 2 金，并把金钱截断到 30,000。
- `citycmdc.c:TreatMake`：每次宴请消耗金钱，目标恢复 50 体力；非君主忠诚增加 1，最高 100。
- `citycmde.c:DepredateMake` 与 `citycmd.c:DepredateDrv`：掠夺将民忠、农业、商业减半；获得 `(智力 + 武力) * 5` 粮与 `(智力 + 武力) * 2` 金。生成函数错误地复用征兵合法性/体力索引，但 `order.h` 两者都声明为 4。

当前 Web 版已经接入三项命令，并保留上述比率、恢复量、属性公式及整数折半。以下属于明确的现代安全规则或临时产品规则：

- 交易和掠夺使用 30,000 的项目资源软上限；历史已超限值保持原值，不会因执行命令向下截断。交易会拒绝导致卖粮少收金钱的数量，而不是复刻原版先卖出再截断的隐藏损失。
- 交易和掠夺各消耗 4 体力并占用本月行动；固定 C 的运行时成本表未进入 allowlist，4 体力仍按可替换产品规则处理。
- 宴请暂定每次 50 金，不消耗体力、不占用或重置目标的本月行动；这与固定 C 实际路径一致，但精确金钱成本仍为 provisional。
- 掠夺使用装备后的有效智力与武力，执行前拒绝不安全的数值，并要求玩家通过危险预览二次确认；AI 不把掠夺当作常规经营。
- 原版允许无收益交易和重复宴请；Web 版拒绝无收益交易和对已满状态目标的宴请，以避免误扣资源。掠夺即使因软上限获得 0 资源仍可执行，但危险预览会显示实际收益与三项折半后果。
