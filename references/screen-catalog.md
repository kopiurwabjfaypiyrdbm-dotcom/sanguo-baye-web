原版截图和录屏默认保存在 `.reference/captures/`，不提交到 Git。确认有再分发权限后，才可将必要材料移入正式文档。

## 采集要求

- 记录来源版本、剧本、君主、日期、操作路径和窗口尺寸。
- 原始画面不缩放、不滤镜处理；另存一份 nearest-neighbor 放大预览。
- 动态界面同时记录关键帧和输入序列。
- 文件名使用稳定编号，例如 `S010-main-menu-original.png`。

## 已确认的源码元数据

### S010 主菜单

- `gamEng.c:GamMainChose/GamPicMenuInner`：初始焦点为索引 0；上/左减一、下/右加一并循环；确认返回当前索引，退出返回 `0xff`。点击在按钮矩形内直接选择。
- 固定顺序与矩形：新君登基 `(6,45)–(73,63)`、重返沙场 `(83,45)–(151,63)`、制作群组 `(6,70)–(73,88)`、解甲归田 `(83,71)–(151,88)`。
- Web 移植可按窗口缩放触摸矩形，但 `exportjs.c` 明确把 160×96 标为原始分辨率；现代主题应保留语义顺序，不必保留像素热区大小。

### S020 时期选择

- 入口路径：S010 索引 0 → `GamPicMenu` → `LoadPeriod(index + 1)`。
- 固定顺序与矩形：董卓弄权 `(0,24)–(78,56)`、曹操崛起 `(0,62)–(78,93)`、赤壁之战 `(81,24)–(158,56)`、三国鼎立 `(81,62)–(158,93)`。
- 键盘焦点规则与 S010 相同；点击四个矩形外会退出时期选择并返回主菜单。

### S030 君主选择

- 入口路径：`LoadPeriod` → `GetAllKings` → `GamGetKing`。列表顺序来自当前时期的君主队列，不能按现代名称或势力强度重排。
- 上/下逐项移动并滚动，确认选择；退出返回 `0xffff`。触摸单击未选项只移动焦点，再次点击当前项确认；返回按钮位于右上。
- 画面同时显示君主列表和其所属城市位置，计时消息会闪烁这些城市。后续现代化可以改为持续高亮，但必须保留“选择君主时可识别其领地”的信息功能。
