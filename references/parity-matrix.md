# 原版一致性矩阵

状态定义：

- `未开始`：尚未定位原版行为。
- `已定位`：已找到源码入口，但没有测试。
- `实验中`：已有样例或临时实现，尚未证明一致。
- `一致`：已通过固定输入的差分测试。
- `有意变化`：为了现代化体验明确改变，并已记录原因。

| 模块 | 上游事实源 | 当前实现 | 状态 | 下一验证 |
|---|---|---|---|---|
| 游戏主循环 | `gamEng.c`、`GamBaYeEng` | `turn.ts` | 实验中 | 记录一个完整原版月份的阶段顺序 |
| 剧本加载 | `LoadPeriod`、`.lib` | `sampleState.ts` | 未开始 | 解析四时期基础数据 |

| 城池命令 | `citycmd*.c` | 无 | 未开始 | 列出全部命令、消耗和执行条件 |
| 月度结算 | `tactic.c`、阶段钩子 | `economy.ts` | 实验中 | 固定城池数据对照一个月结果 |
